# 旁白讀音檢測報告（remaster v2 / pronunciation）

共 36 段旁白、32 項發現：high 14、medium 10、low 5、info 3；建議重合成 **21 句**（分布在 16 段）。

## 最重要的結論

1. **系統性 bug：OpenCC `t2s` 不會把助詞「著」轉成「着」**，簡體「著」是 zhù/zhuó，模型 4 處都唸成 **zhù（第四聲、完整時長）**：沿著、看著、積著、亮著。修法：`cosy_tts._once` 在 `t2s` 後加 `.replace('著','着')`。
2. **兩岸讀音差異字幾乎都唸成大陸音**（F0 聲調實測）：究竟、期間、時期、前夕、深褐色、檔案、舊檔室、字跡、痕跡、突然、微弱。例外：意識（唸成台灣 shì）、潮汐、第一次的「舊檔案」偏台灣調。
3. whisper＋聲學複核找出幾處疑似唸錯：刁才弟（第一章_01_05 唸成 diū）、「我**忽**然意識到」（唸成 gù）、殘缺、側寫、屋頂、沖散、回答、多夢者 —— 標為疑似，重生前請試聽。
4. 多音字（重、長、處、曾、乾隆、傳、更、數、散、卷…）依 F0／CTC 都是正確讀音；只有「照片」的「片」偏大陸口語 piān（low）。

## 方法與限制

- **lexical**：tw_cn_diff.json（67 條）逐字詞掃描 narration.json；多音字依上下文人工判定台灣讀音（analyze.py POLY）
- **asr**：faster-whisper medium（CPU int8, beam 5, word_timestamps）轉寫 raw.wav；簡體＋拼音層逐字對齊
- **align**：torchaudio MMS_FA 強制對齊（無聲調拼音）取得每個音節在 raw.wav 的時間
- **tone**：pyworld harvest F0 → 半音、5 點輪廓等 11 維特徵 → GradientBoosting；以同一批旁白中兩岸同音、非多音字的 1106 個音節訓練，5-fold 交叉驗證 4 類準確率 0.822、兩兩比較 {'1v2': 0.899, '1v3': 0.935, '1v4': 0.937, '2v3': 0.887, '2v4': 0.97, '3v4': 0.88}
- **segment**：聲母韻母不同的候選用 MMS CTC loss 在該音節 ±0.1 s 視窗比較（loss 越小越像）
- **limits**：F0/CTC 是機器推測，不等於人耳判定；單音節 CTC 視窗短、易受前後音節影響；C 類都標為疑似，建議重生前先試聽。whisper 僅 medium（large-v3 未下載，未使用）。
- **time_mapping**：raw_wav_sec＝CosyVoice 原始輸出（<key>.raw.wav）；post_wav_sec≈(raw−lead_trim)/tempo（narr_post 的 rubberband 變速，誤差約 ±0.15 s）；v1_video_tc＝字幕 .ass 該段起點＋post 秒數

## cosy_tts 切句規則與「只換一句」

- **split**：split_sentences：依 。！？ 切句；單句 >40 字再依 ，、；： 切；相鄰句併成 16–56 字的合成單位
- **gap**：合成單位之間插入 SENT_GAP=0.35 s 的數位靜音（樣本值全 0），本報告用這段全 0 區間精確定位每句在 raw.wav 的起訖；36 段全部偵測到的間隔數＝預期數（沒有句子被拆成子句重合成）
- **replace_one**：只換一句：用 tts_text 重合成該合成單位 → 取代 raw.wav 中 raw_sec 區間（前後 0.35 s 靜音保留）→ 重跑 narr_post.py 該段（narr_post 會從 raw.wav 重做整段後製，時長會小幅改變，render 時間軸跟著變）
- **cer_note**：cosy_tts._best 的 CER 以原文拼音（大陸音）評分；改用替代字後，CER 參考文字也要換成 tts_text，否則台灣音會被當錯

## 檔案

- `tw_cn_diff.json`：兩岸讀音差異表（可重用；`build_diff_table.py` 產生）
- `lexical_hits.json`：文字面命中＋多音字出現位置
- `asr_medium.json`：whisper 逐詞轉寫（raw.wav 時間）
- `analysis.json`：每段切句位置、ASR 差異、音節對齊、F0 聲調判讀
- `asr_verify.json` / `zhe_verify.json`：ASR 差異與「著」的聲學複核
- `analyze.py` / `verify_asr.py` / `verify_zhe.py`：在 WSL `~/.venv-cosy` 重跑（`run.sh` / `py.sh`）
- `tone_clf.pkl`：本批旁白訓練的聲調分類器（重生後可直接複查新音檔）
