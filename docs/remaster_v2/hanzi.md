## 方法

- **sampling**：每段 clip 以 2 fps（每 0.5 秒）抽全長幀＋最後一幀，共 1257 幀；成片只用到 [src_head, src_used_end]，報告只算這段
- **ocr**：PaddleOCR 3.5（PP-OCRv5_server det/rec, lang=ch, GPU），det_thresh=0.2 / box_thresh=0.4，不設辨識門檻
- **tracking**：同 clip 內以 IoU / 中心距離串接跨幀框（容許 3 幀空缺），共 304 條軌跡
- **camera**：ORB 特徵 + estimateAffinePartial2D 估相機運動（僅成片使用區間）；物件運動另以軌跡首尾框的縮放與位移判定
- **vlm**：Ollama qwen3-vl:30b-a3b-instruct，以 num_gpu=0 在 CPU 跑（GPU 已被他人佔滿，且避免擠掉已常駐的 qwen2.5vl:7b）；qwen2.5vl:7b 試跑 3 張即嚴重幻覺（把模糊假字讀成「龍鳳會堂書記」），棄用
- **final_judge**：每條軌跡由 Claude 逐張檢視裁切圖（review/tracks_*.jpg）與代表幀總覽（overview/*.jpg）後人工判定；VLM 只當旁證

## 限制與未驗證事項

- 抽樣間隔 0.5 秒：短於 0.5 秒的閃現字可能漏掉（**未驗證**）。
- OCR 會漏抓：例如 H019 的禁止標誌 OCR 完全沒偵測到，是人工看總覽圖補的。其他 OCR 沒抓到、人工也沒注意到的小字可能還有（**未驗證**完整覆蓋）。沒有物件的 clip （034, 035, 041, 043）代表「沒發現需要列的字」，不代表畫面裡一定沒有字。016、026、039 的極小字是第二輪複查才補上的（H103–H105）。
- 時間軸對照已驗證：從 v1 成片抽 01:48.0 與 07:50.0 兩格，分別是 H025 的檔案簿特寫與 H084 的燈籠特寫，與推算一致。其餘時間碼由同一公式推得，沒有逐項抽驗。
- `_t` clip 開頭 2.5 秒（CUT_HEAD）在成片中被剪掉，所以只出現在那段的字不列入。
- 重要度分數由面積、停留秒數、是否在畫面中央與物件類型自動算出，再由人工把 c 類降級；可修難度（object_motion）來自 ORB 相機估計和 OCR 框軌跡，OCR 框本身會抖，只能當參考。
- VLM 只當旁證：qwen2.5vl:7b 試 3 張就嚴重幻覺，已棄用；qwen3-vl:30b 在 CPU 上每張約 30–55 秒，而且代表幀普查時常把假字標成 `fake:false`、自己編出可讀字，所以**最終判定一律以人工逐張看裁切圖為準**。VLM 實際覆蓋範圍見 report.json 的 `vlm_frame_survey` 與各項 `vlm_crop_votes`。空的代表沒跑到。
- 建議文字的字數是依畫面上的字格數估的，實際貼字前請再對一次格數。

## 局部修補建議（不重生整段）

- **a 換字**：用 OpenCV 在 bbox 內追特徵點，估出逐幀 homography（平面物件：匾、聯、桌裙、紙頁、路面標字）；也可以用 CoTracker3 追四角。字用開放授權楷體（全字庫正楷體 TW-Kai，或教育部標準楷書）以 PIL 算圖，再依原字的顏色與筆觸做金漆、墨色、褪色，最後用 `cv2.seamlessClone` 或 alpha 疊回，加回顆粒與景深模糊。只重算有這個物件的那幾秒。
- **b 抹除**：用 ProPainter（開源影片修補，吃 mask 序列）只處理 bbox 範圍的幀；比較簡單的做法是局部高斯模糊或加水漬紋理，蓋掉字形但保留物件輪廓。曲面（燈籠）或快速搖移的物件，換字失敗時的退路就是 b。
- 貼字對象是原始 clip（1056×608、未調色），修完再走 render.py 的縮放、慢動作與調色流程；也可以直接在 norm 中間段上修，但要注意那邊已經過 minterpolate 補幀。
